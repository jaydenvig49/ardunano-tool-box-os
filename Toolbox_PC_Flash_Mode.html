Important, no fake buttons

A standalone HTML page cannot compile an arbitrary .ino by itself. This tool accepts your .ino for viewing, but the Arduino compiler is needed to turn it into firmware. Once compiled, this page can send a supported Intel HEX file over Web Serial.

Best in desktop Chrome or Edge. Web Serial normally requires a secure context and a compatible USB serial device. This page never sends files to a website.

Compile it in Arduino IDE

  1. Open your sketch in Arduino IDE.
  2. Select the correct board and processor.
  3. Click Sketch → Export Compiled Binary.
  4. Find the generated .hex file in the sketch folder.
  5. Open the USB Flash tab and select that HEX file.
For a classic Nano, verify the processor/bootloader setting (often ATmega328P or ATmega328P Old Bootloader). The wrong setting can prevent upload.
